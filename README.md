# 失踪在1999（Missing in 1999）

网页解密游戏《失踪在1999》，已获原制作团队青川工作室许可发布。

## 在线体验

<https://qingchuanhub.github.io/missingin1999/>

## 故事

你收到一台旧电脑——失踪多年的哥哥「林远」寄来的。

寄件人自称「老周」。桌面是 2008 年的 Windows XP。所有线索，都在这台电脑里。

## 玩法主线

1. 聊天记录 → 摩尔斯电码 → 4 位密码
2. 加密日记 → Base64 乱码
3. 博客「原文件」→ 凯撒暗语
4. 时光论坛 → ROT13 → 真相

## 难度

登录界面可选：

| 难度 | 说明 |
| ---- | ---- |
| 简单 | 提示详尽，几乎手把手带路 |
| 普通 | 标准解谜体验 |
| 困难 | 提示隐晦、隐藏解码表，全靠自己推理 |

## 技术

原生 HTML / CSS / JS，无任何依赖，纯静态。
可直接双击 `index.html` 运行，也可部署到任意静态托管（GitHub Pages 等）。
